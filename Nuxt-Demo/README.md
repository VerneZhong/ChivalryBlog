# Nuxt Minimal Starter

## 

## Setup
install vue-toastification 
```
npm install vue-toastification
```

Make sure to install dependencies:

```bash
# npm
npm install
```

```bash
# npm
npm run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build
```

Locally preview production build:

```bash
# npm
npm run preview
```
